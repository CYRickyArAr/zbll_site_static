# ZBLL 公式数据库

<p align="center">
  <strong>简体中文</strong> | <a href="README.en.md">English</a>
</p>

一个收录 **472 个 ZBLL 情况**的在线数据库，含顶层状态图、多行公式与选手实战标注。

ZBLL（Zborowski-Bruchem Last Layer）是魔方顶层还原的最后一步公式体系。本站按 [pepkin88 zbll-explorer](https://pepkin88.me/zbll-explorer/) 官方分类，完整收录全部 472 个 case，并标注了 **多位顶尖选手**（耿暄一、Tymon Kolasiński、Feliks Zemdegs、南承赫、Max Park 等）在实战中使用过的公式。

公式与选手标注来源自 [reco.nz](https://reco.nz/)、魔方星球（Cubestation）与 WCU CUBE。标注可保证该公式确被对应选手使用过，但不保证是选手目前的主力公式，仅供学习参考。

## 内容

- **472 个情况全集**：每个情况附带顶层状态图与多行公式。
- **7 大分类**：H（40 个情况）、U / T / L / Pi / S / AS（各 72 个情况）。
- **选手实战标注**：每条公式标注使用过它的选手，同一条公式被多人使用时会合并显示（如「耿 Tymon 藩」）。
- **本地公式库**：支持默认大神版预览、大神版个人副本、自定义公式库与 `.zbll` 文件导入导出。

## 使用

打开网站即可浏览全部分类，点击分类进入查看公式；点子分类标题可折叠/展开，也可用顶部按钮全部展开/折叠。顶部支持在“大神版”和“自定义”之间切换，并可按“全部 / 已学 / 未学”筛选。

右上角可打开本地工作区：

- **默认大神版**：仅预览，不直接改动原始数据库。
- **大神版公式库**：基于默认大神版创建个人副本，仅支持编辑备注、排序、学习状态。
- **自定义公式库**：可任意编辑公式、图片和备注。
- **导入 / 导出 `.zbll`**：本地数据保存在当前浏览器中，导出 `.zbll` 后可跨设备继续编辑。

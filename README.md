# ZBLL 公式库

<p align="center">
  <strong>简体中文</strong> | <a href="README.en.md">English</a>
</p>

一个收录 **472 个 ZBLL 情况**的在线公式库，包含顶层状态图、多套公式与选手实战使用标注。

ZBLL（Zborowski-Bruchem Last Layer）是一套在顶层棱块已定向的情况下，一步完成最后一层的公式体系。本站采用 [pepkin88 zbll-explorer](https://pepkin88.me/zbll-explorer/) 的分类方式，完整收录 472 个 ZBLL 情况，并标注 **多位顶尖选手**（耿暄一、Tymon Kolasiński、Feliks Zemdegs、南承赫、Max Park 等）实际使用过的公式。

本站公式整理自 [reco.nz](https://reco.nz/)、[魔方星球](https://cubestation.com/)、[WCU Cube](https://wcucube.club/) 的复盘记录，具有**100%真实性**（免责声明：只保证选手实战使用过，不保证是当前主力公式）。

内容仅供学习与参考，本站将持续更新。**如发现公式错误或其他问题，欢迎反馈指正。**

## 内容

- **472 个 ZBLL 情况**：每个情况均提供顶层状态图及对应公式，部分情况收录多套公式。
- **7 大分类**：H（40 个情况），U / T / L / Pi / S / AS（各 72 个情况）。
- **选手实战标注**：标注每条公式实际使用过的选手；多人使用同一公式时合并显示（如「耿 Tymon 藩」）。
- **默认大神版**：整理自顶尖选手实战使用记录，可直接预览。
- **个人公式库**：在同一个库中选择显示哪些大神公式、添加自己的公式，并通过 `.zbll` 文件备份或迁移。

## 使用

### 浏览与选择公式库

点击顶部「文 / A」语言图标可切换「简体中文 / English」。首次访问跟随浏览器语言，手动选择后会记住。英文模式会转换已知选手的展示简称（如耿 → Xuanyi、南 → Nahm）；个人库名、备注和标记编辑框里的原文保持不变。

打开网站即可浏览。进入分类后，通过顶部的分类文字和子分类图片切换情况，也可按「全部 / 已学 / 未学」筛选；点击左上角网站标志返回首页。

右上角按钮显示当前公式库名称，点击可打开公式库管理：

- **默认大神版**：仅供预览，无需创建公式库即可浏览。首次修改时，会提示创建自己的公式库。
- **个人公式库**：点击新建按钮创建，初始显示全部大神公式。每个库都可选择大神公式、添加自己的公式，并保存图片、备注和学习状态；不同库的内容与设置互不影响。
- **管理公式库**：点击库名切换；个人库右侧菜单可重命名、导出或删除。

### 编辑与学习

在个人公式库中，点击情况卡片上的「编辑」：

- **大神公式**：逐条勾选显示或隐藏，也可对当前情况「全选 / 全不选」。原公式及选手标注不可修改，隐藏不会删除原公式。
- **我的公式**：点击「＋ 添加」，左侧输入公式，右侧填写标记（可选，多个标记用空格分隔）。公式可随时修改；右侧「删除」会删除整条个人公式及其标记。
- **图片与备注**：可更换、清除或恢复图片，填写备注。备注可输入多行，浏览时以单行省略显示。
- **保存 / 取消**：编辑完成后点击「保存」；点击「取消」放弃本次修改。

点击卡片右下角圆形勾选按钮可标记或取消已学，拖动卡片右上角手柄可调整情况顺序。每个情况还可点击选中一条公式并持续高亮，再次点击取消；选中不会改变公式顺序。

### 备份与迁移

编辑后先点击「保存」，再从个人公式库菜单中导出 `.zbll`。文件包含自己的公式与标记、各情况的大神公式显示／隐藏设置，以及图片、备注、学习状态、排序和公式选中状态。

在其他浏览器或设备上打开公式库管理，点击「导入 .zbll」即可恢复为一个独立的个人公式库。

**个人公式库保存在当前浏览器中，不会自动跨设备同步。清理浏览器数据可能导致丢失，请定期导出备份。**
